# Natas

Natas é uma série de desafios focada em Segurança Web.

O objetivo aqui é entender e explorar vulnerabilidades em aplicações web, tais como:

- Injeção de HTML/JS, Cross-Site Scripting (XSS)
- Injeção e manipulação de parâmetros (SQLi, command injection)
- Autenticação fraca, lógica de sessão e problemas de autorização
- Configurações de servidor e exposição de arquivos sensíveis
