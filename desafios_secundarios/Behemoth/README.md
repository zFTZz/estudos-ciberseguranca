# Behemoth

Behemoth (desafios secundários) foca em exploração de binários e engenharia reversa avançada.

Áreas de estudo:

- Instrumentação e fuzzing
- Exploração de heap/stack e vulnerabilidades complexas
- Análise aprofundada de código compilado e mitigations

Armazene relatórios detalhados, PoCs e scripts nesta pasta.
